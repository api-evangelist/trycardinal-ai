# Cardinal

> Cardinal is an AI platform for precision outbound sales — "revenue agents for
> high-growth companies." Its agents build and refresh account lists from signals,
> monitor what prospects post and engage with, generate personalized snippets, and
> orchestrate end-to-end email and LinkedIn plays, while capturing inbound from website
> visitors, product signups and ad impressions. Cardinal is a Y Combinator Winter 2026
> company founded by Devishi Jha and Jianna Liu, based in San Francisco, and names
> Mintlify, Deepgram, Greptile, Giga and Luminai among its customers. It sells a
> half-software, half-service model: it wires into a customer's existing GTM stack,
> reads from and writes back to their CRM, and builds agents around plays that already
> work for them. As of 2026-08-13 it publishes no public API, no developer portal and no
> documentation site.

## APIs

Cardinal publishes no public API. Contract discovery on 2026-08-13 probed four hosts
across two domains — www.trycardinal.com, trycardinal.ai, app.trycardinal.ai and
api.trycardinal.ai — for OpenAPI, Swagger, GraphQL SDL, AsyncAPI, MCP `tools/list`,
llms.txt and A2A agent cards, and found none. See the x-coverage block in apis.yml for
the probed URLs and their HTTP statuses.

Three things are worth knowing about that absence:

- **An API exists; it is simply not public.** Cardinal's own status page declares
  exactly one component and its name is "API" (operational, 100% uptime over the
  rolling three-month window). Every `/api/*` path on the customer application returns
  HTTP 401 `{"error":"Unauthorized"}`.
- **The API hostname is dangling.** `api.trycardinal.ai` resolves by CNAME to a Render
  service that no longer exists (`x-render-routing: no-server`) and presents no TLS
  certificate, so HTTPS fails at the handshake.
- **No documentation host exists at all.** `docs.trycardinal.ai` and
  `docs.trycardinal.com` have no DNS record.

## Domain note

Cardinal moved its marketing site from trycardinal.ai to trycardinal.com during 2026:
`https://trycardinal.ai/` HTTP 301s to `https://www.trycardinal.com/`, and the former
deep pages on the .ai domain (`/company`, `/product`) now return 404. The .ai domain is
not abandoned — it still carries the customer application, the status page, the
published contact address and the company's analytics identity. The API Evangelist slug
`trycardinal-ai` is retained.
